═══════════════════════════════════════════════════════════════════════
                      ملاحظات مهمة
═══════════════════════════════════════════════════════════════════════

1. يفضل استخدام الأمر: npm install
   لتثبيت كل المكتبات من ملف package.json مباشرة

2. إذا واجهت مشاكل في التثبيت، جرب:
   npm cache clean --force
   ثم أعد المحاولة

3. تأكد من وجود Node.js نسخة 18 أو أحدث:
   node --version

4. إذا كنت تستخدم Windows، شغل CMD كمسؤول (Run as Administrator)

5. المساحة المطلوبة: حوالي 500-600 ميجابايت
